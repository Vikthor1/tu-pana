- Current development workflow
- AI tool roles and boundaries
- Onboarding briefs for AI systems (Hermes, Aider)

**What does NOT belong here:**
- Architecture docs → `docs/current-architecture.md`
- Pedagogical philosophy → `docs/project-brief.md`
- QA test scenarios → `prompts/qa-scenarios.md`
- Architectural decisions → `docs/decisions/`
