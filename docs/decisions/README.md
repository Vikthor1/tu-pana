# docs/decisions/

Records of significant architectural decisions and the reasoning behind them.

**What belongs here:**
- Architecture principles (commitments that must survive future changes)
- Decision records: what was decided, why, what was rejected

**What does NOT belong here:**
- How-to guides → `docs/workflow/`
- Current state → `docs/current-architecture.md`
- Feature ideas → `docs/ideas/`
- Testing → `docs/testing/`
