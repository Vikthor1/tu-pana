# docs/ideas/

Consciously parked ideas and deferred possibilities.

**What belongs here:**
- Feature ideas deliberately deferred
- Experimental directions not on the active roadmap
- Notes on what was considered and rejected (with brief reasoning)

**What does NOT belong here:**
- Active tasks → tracked in conversation or personal notes
- Decisions already made → `docs/decisions/`
- Workflow docs → `docs/workflow/`

**Note:** An idea being here is not a commitment. This is a parking lot, not a queue.
